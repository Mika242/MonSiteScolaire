Série 1 — Résoudre une équation du second degré

Sans discriminant : par factorisation

📖 Qu'est-ce qu'une équation du second degré ?

Une equation du second degre est une equation qui peut s ecrire sous la forme ax²+bx+c=0, avec a différent de zero. En seconde, on apprend a la résoudre dans des cas particuliers, en utilisant la factorisation : la méthode générale avec le discriminant sera vue en première.

ax² + bx + c = 0 (a ≠ 0)
Pourquoi a doit être différent de zéroSi a=0, il ne reste que bx+c=0, ce qui est une simple equation du premier degre, pas du second degre. La condition a≠0 est donc essentielle pour parler d equation du second degre.
📖 Cas particulier : b=0

Quand le coefficient b est nul, l equation devient ax²+c=0, qui se resout facilement en isolant x².

ax² = -c ⟺ x² = -c/a
🔢 Méthode selon le signe de -c/a
  • Si -c/a > 0 : deux solutions, x = √(-c/a) et x = -√(-c/a).
  • Si -c/a = 0 : une seule solution, x = 0.
  • Si -c/a < 0 : aucune solution reelle (un carre ne peut pas être négatif).
Exemple résolu : b=0 x² - 25 = 0 ⟺ x² = 25 ⟺ x = 5 ou x = -5 x² + 9 = 0 ⟺ x² = -9 : aucune solution reelle
📖 Cas particulier : c=0

Quand le coefficient c est nul, on peut factoriser directement par x, ce qui transforme l equation en equation-produit.

ax² + bx = x(ax+b) = 0
Exemple résolu : c=0 2x² - 6x = 0 2x(x-3) = 0 x = 0 ou x = 3

Q3 Intermédiaire

Résous l'équation 3x² - 12x = 0, en détaillant ta méthode.

Le coefficient c est nul, on peut donc factoriser directement par x.
3x² - 12x = 3x(x-4) = 0.
D après la règle du produit nul : 3x=0 (donc x=0) ou x-4=0 (donc x=4). Les solutions sont x=0 ou x=4.

Série 2 — Factorisation par identité remarquable et inéquations

Cas général et tableau de signes

📖 Factoriser grâce à une identité remarquable

Certaines equations du second degre correspondent directement a une identite remarquable, ce qui permet une factorisation immediate.

Exemple résolu : carré parfait x² + 6x + 9 = 0 (x+3)² = 0 (identite remarquable a²+2ab+b²) x = -3 (solution unique)
📖 Factoriser grâce à une racine évidente

Si l on connait ou devine une racine x0 de l equation (une valeur qui l annule), on peut alors factoriser l expression par (x-x0), puis effectuer une division pour trouver l autre facteur.

🔢 Méthode par racine évidente
  • Tester quelques valeurs simples (0, 1, -1, 2...) pour trouver une racine qui annule l expression.
  • Une fois la racine x0 trouvee, on sait que (x-x0) est un facteur de l expression.
  • Effectuer la division pour trouver le second facteur.
  • Ecrire l equation sous forme factorisee, puis appliquer la règle du produit nul.
Exemple résolu : racine évidente et division x² - 5x + 6 = 0 On teste x=2 : 4-10+6=0. Donc x=2 est une racine, et (x-2) est un facteur. En divisant : x²-5x+6 = (x-2)(x-3) x = 2 ou x = 3
📖 Les inéquations du second degré

Pour résoudre une inequation du second degre, on factorise d abord l expression, puis on etudie son signe grace a un tableau de signes.

Exemple résolu : inéquation du second degré résoudre x² - 4x + 3 ≤ 0 On factorise : x²-4x+3 = (x-1)(x-3) Tableau de signes : le produit est négatif entre 1 et 3, positif a l exterieur Solution : 1 ≤ x ≤ 3
Lien avec la paraboleL equation y=ax²+bx+c représente une parabole. Si a>0, elle est tournee vers le haut. Les solutions de ax²+bx+c=0 correspondent aux points ou la parabole coupe l axe des abscisses.

Q2 Intermédiaire

Résous l'équation x² - 7x + 12 = 0, en cherchant une racine évidente puis en factorisant.

On teste x=3 : 9-21+12=0. Donc x=3 est une racine, et (x-3) est un facteur.
En divisant x²-7x+12 par (x-3), on obtient (x-3)(x-4).
D après la règle du produit nul : x=3 ou x=4.
⭐⭐⭐ Avancé
Q3 Avancé

Résous l'inéquation x² - x - 6 ≤ 0, en détaillant ta méthode (factorisation puis tableau de signes).

On cherche une racine evidente : on teste x=3, ce qui donne 9-3-6=0. Donc (x-3) est un facteur.
En divisant, on obtient x²-x-6 = (x-3)(x+2).
Tableau de signes : le produit (x-3)(x+2) est négatif entre -2 et 3, positif a l exterieur. L ensemble solution de l inequation ≤0 est donc [-2;3].

Problèmes — Contextes variés

Le second degré en situation

Problème 1 — Aire d'un jardin carré
Intermédiaire

Un jardin carré a un côté de longueur x mètres. On sait que son aire vaut 64 m². Détermine la longueur du côté du jardin.

On pose l equation : x² = 64.
On resout : x = 8 ou x = -8.
Comme x représente une longueur, elle doit être positive : on ne garde que x=8. Le cote du jardin mesure 8 metres.
Problème 2 — Trajectoire d'une balle
Avancé

La hauteur d'une balle lancée est modélisée par h(x) = -x² + 6x, où x est le temps en secondes et h la hauteur en mètres. Détermine à quels instants la balle touche le sol (h=0).

On resout l equation -x²+6x=0.
On factorise par x : -x²+6x = x(-x+6) = 0.
x=0 (moment du lancer) ou -x+6=0, soit x=6. La balle touche le sol au bout de 6 secondes (x=0 correspondant simplement au moment du lancer, pas a un vrai retour au sol).
Problème 3 — Deux nombres et leur produit
Avancé

Trouve deux nombres entiers consécutifs dont le produit vaut 56, en posant une équation du second degré.

On note x le premier nombre, x+1 le second. On pose l equation : x(x+1) = 56, soit x²+x-56=0.
On cherche une racine evidente : on teste x=7, ce qui donne 49+7-56=0. Donc (x-7) est un facteur.
En factorisant, x²+x-56 = (x-7)(x+8) = 0, donc x=7 ou x=-8. Avec x=7, on obtient les nombres 7 et 8 (7×8=56, ce qui convient).
Problème 4 — Zone d'un signal positif
Avancé

Un signal est modélisé par f(x) = x² - 2x - 8. Détermine pour quelles valeurs de x ce signal est négatif (f(x) < 0).

On cherche une racine evidente : on teste x=4, ce qui donne 16-8-8=0. Donc (x-4) est un facteur.
En factorisant, x²-2x-8 = (x-4)(x+2).
Tableau de signes : le produit (x-4)(x+2) est négatif entre -2 et 4. Le signal est donc négatif pour x dans l intervalle ]-2;4[.
