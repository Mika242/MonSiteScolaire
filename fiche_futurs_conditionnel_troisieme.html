Série 1 — Exprimer le futur

WILL et BE GOING TO

📖 WILL : une prédiction ou une décision spontanée

WILL s utilise pour exprimer une prediction non planifiee, une promesse, ou une decision prise au moment ou l on parle (decision spontanee).

Sujet + WILL + base verbale (ex: I will help you.)
Exemple résolu : décision spontanée Le telephone sonne. 'I'll answer it!' (decision prise a l instant, sans y avoir reflechi avant)
📖 BE GOING TO : un projet ou une intention

BE GOING TO s utilise pour exprimer un projet deja decide avant le moment ou l on parle, ou une prediction basee sur des signes visibles dans le present.

Sujet + BE (conjugue) + going to + base verbale (ex: She is going to visit Paris next month.)
Exemple résolu : prédiction basée sur des signes visibles On regarde le ciel tres noir : 'Look at those clouds! It's going to rain.' (prediction basee sur un signe visible maintenant, pas une decision spontanee)
Bien distinguer WILL et BE GOING TOWILL = decision prise SUR LE MOMENT, sans preparation. BE GOING TO = projet DEJA DECIDE avant, ou prediction basee sur des indices visibles maintenant. Comparer : 'I will call her' (je decide maintenant) vs 'I am going to call her' (c est deja prevu).

Série 2 — Les if clauses (conditionnels)

Exprimer une hypothèse

📖 Le conditionnel de type 1 (situation réelle possible)

Le conditionnel de type 1 exprime une situation reelle ou possible dans le futur, une condition realisable.

If + present simple, ... will + base verbale
Exemple résolu : conditionnel type 1 'If it rains, I will not go out.' (si il pleut -> possible -> je ne sortirai pas)
📖 Le conditionnel de type 2 (situation hypothétique peu probable)

Le conditionnel de type 2 exprime une situation hypothetique, imaginaire ou peu probable dans le present ou le futur.

If + preterit simple, ... would + base verbale
Exemple résolu : conditionnel type 2 'If I won the lottery, I would travel around the world.' (hypothese peu probable : gagner au loto)
Le cas spécial de BE : 'were' pour tout le mondeAu conditionnel de type 2, on utilise souvent 'were' (plutot que 'was') meme avec 'I' ou 'he/she/it', surtout dans l expression figee 'If I were you...' (a ta place...).
📖 Le conditionnel de type 3 (irréel du passé)

Le conditionnel de type 3 exprime un regret ou une situation imaginaire dans le PASSE : quelque chose qui aurait pu se produire mais qui ne s est pas produit.

If + past perfect, ... would have + participe passe
Exemple résolu : conditionnel type 3 'If I had studied harder, I would have passed the exam.' (regret : je n ai pas etudie assez, donc je n ai pas reussi)

Problèmes — Contextes variés

Les futurs et le conditionnel en situation

Problème 1 — Un projet de vacances
Intermédiaire

Une famille a déjà réservé son hôtel pour l'été. Complète : 'We ___ (go) to Spain this summer.' avec la structure adaptée à un projet déjà décidé.

Comme le projet est deja decide (l hotel est reserve), on utilise BE GOING TO.
'We are going to go to Spain this summer.'
Problème 2 — Un conseil hypothétique
Avancé

Complète avec le conditionnel de type 2 pour donner un conseil : 'If I ___ (be) you, I ___ (apologize) immediately.'

Conditionnel type 2 : if + preterit ('were', forme speciale pour BE), would + base verbale.
'If I were you, I would apologize immediately.'
Problème 3 — Un regret sur un examen raté
Avancé

Transforme en conditionnel de type 3 : 'I forgot my notes, so I failed the test.'

Conditionnel type 3 : if + past perfect, would have + participe passe.
'If I hadn't forgotten my notes, I wouldn't have failed the test.'
Problème 4 — Comparer les trois types
Avancé

Explique la différence de sens entre : A) 'If it rains, I will stay home.' B) 'If it rained, I would stay home.' C) 'If it had rained, I would have stayed home.'

Phrase A (type 1) : situation possible dans le futur, la pluie pourrait vraiment arriver.
Phrase B (type 2) : situation hypothetique, moins probable, imaginee au present/futur.
Phrase C (type 3) : regret sur le passe, il n a probablement pas plu et la personne n est donc pas restee chez elle. Ces trois phrases montrent une gradation dans le degre de realite/probabilite de la condition.
