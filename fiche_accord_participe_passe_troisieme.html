Série 1 — Le participe passé avec être et employé seul

Les deux règles les plus simples

📖 Le participe passé employé avec l'auxiliaire ÊTRE

Quand le participe passe est conjugue avec l auxiliaire ETRE, il s accorde TOUJOURS en genre (masculin/feminin) et en nombre (singulier/pluriel) avec le SUJET du verbe. C est la regle la plus simple et la plus systematique.

Sujet + ETRE + participe passe accorde avec le SUJET
Exemple résolu : accord avec être Sujet feminin singulier : 'Elle est partie.' (participe accorde au feminin singulier) Sujet masculin pluriel : 'Ils sont partis.' (participe accorde au masculin pluriel) Sujet feminin pluriel : 'Les eleves sont rentrees de l ecole.' (accorde au feminin pluriel)
Peu importe où se trouve le sujetAvec l auxiliaire ETRE, on accorde TOUJOURS avec le sujet, quelle que soit sa position dans la phrase, et meme s il y a aussi un COD dans la phrase. Cette regle ne connait quasiment aucune exception (a part les verbes pronominaux, voir Serie 2).
📖 Le participe passé employé seul (comme un adjectif)

Quand le participe passe est employe SEUL, sans auxiliaire (comme s il etait un simple adjectif qualificatif), il s accorde en genre et en nombre avec le nom qu il qualifie.

🔢 Méthode pour repérer un participe employé seul
  • Verifier qu il n y a aucun auxiliaire (etre ou avoir) directement associe au participe.
  • Identifier le nom que le participe qualifie (comme le ferait un adjectif).
  • Accorder le participe en genre et en nombre avec ce nom, exactement comme un adjectif qualificatif.
Exemple résolu : participe passé employé seul 'Des fleurs coupees avec soin.' (coupees s accorde avec 'fleurs', feminin pluriel, comme un adjectif)

Le verbe 'arriver' est conjugue avec l auxiliaire ETRE ('est arrivee').
La regle de l auxiliaire ETRE impose d accorder systematiquement le participe passe avec le sujet du verbe. Ici, le sujet 'Marie' est feminin singulier, donc le participe 'arrive' devient 'arrivee' (avec un e final).

Série 2 — Le participe passé avec avoir et les verbes pronominaux

La règle la plus complexe, et le principal piège du brevet

📖 Le participe passé avec AVOIR

Avec l auxiliaire AVOIR, la regle est plus subtile qu avec ETRE : le participe passe ne s accorde JAMAIS avec le sujet. Il s accorde UNIQUEMENT avec le complement d objet direct (COD), et seulement si ce COD est place AVANT le verbe dans la phrase.

Avoir + COD place APRES le verbe : participe INVARIABLE Avoir + COD place AVANT le verbe : participe ACCORDE avec le COD
Exemple résolu : comparer les deux cas 'Nous avons prevu ces nouvelles.' (COD 'ces nouvelles' APRES le verbe -> pas d accord : 'prevu' reste invariable) 'Ces nouvelles, nous les avions prevues.' (COD 'les' qui reprend 'ces nouvelles' AVANT le verbe -> accord : 'prevues')
La méthode pour trouver le CODPour identifier le COD d un verbe avec avoir, pose la question 'qui ?' ou 'quoi ?' directement apres le verbe (sans preposition). Exemple : 'J ai mange des pommes.' -> j ai mange QUOI ? Des pommes (COD, place apres, donc pas d accord ici).
📖 Le cas particulier des verbes pronominaux

Les verbes pronominaux (avec 'se' : se laver, se regarder, se parler...) se conjuguent toujours avec l auxiliaire ETRE, mais leur regle d accord n est PAS celle d ETRE habituelle : il faut determiner si le pronom 'se' est COD ou COI (complement d objet indirect) du verbe.

🔢 Méthode pour accorder un verbe pronominal
  • Identifier l action du verbe et se demander : le pronom 'se/s' repond-il a la question 'qui/quoi ?' (alors COD) ou 'a qui ?' (alors COI) ?
  • Si 'se' est COD, le participe s accorde avec lui (donc avec le sujet, puisque se=sujet).
  • Si 'se' est COI, le participe reste INVARIABLE (piege frequent).
  • Verifier s il existe un autre COD explicite dans la phrase, place avant le verbe : dans ce cas, c est avec CE COD que l on accorde, pas avec 'se'.
ExempleAnalyseAccord
Elle s est lavée.s' = COD (elle a lave QUI ? elle-meme)Accord : lavée
Elles se sont téléphoné.se = COI (elles ont telephone A QUI ? l une a l autre)Invariable : téléphoné
Elle s est lavé les mains.les mains = COD (apres le verbe) ; s' = COIInvariable : lavé
Les verbes toujours COI (donc toujours invariables)Certains verbes pronominaux ont systematiquement un pronom COI, jamais COD : se telephoner, se parler, se sourire, se nuire, se plaire, se succeder. Leur participe passe reste donc TOUJOURS invariable, quel que soit le sujet.

Q3 Avancé

Accorde et justifie : 'Les pommes que j'ai ___ (manger).' Explique pourquoi il faut accorder ici.

On cherche le COD du verbe 'manger' : j ai mange QUOI ? 'que', qui reprend 'les pommes' (feminin pluriel).
Ce COD ('que', mis pour 'les pommes') est place AVANT le verbe dans la phrase. Il faut donc accorder le participe avec lui : 'Les pommes que j'ai mangées.'

Problèmes — Contextes variés

L'accord du participe passé en situation

Problème 1 — Une lettre de vacances
Intermédiaire

Corrige les erreurs d'accord dans cette phrase si nécessaire, en justifiant : 'Les cartes postales que j'ai envoyé à mes amis étaient magnifiques.'

On cherche le COD du verbe 'envoyer' : j ai envoye QUOI ? 'que', qui reprend 'les cartes postales' (feminin pluriel).
Ce COD est place AVANT le verbe (avant 'ai envoye') : il faut donc accorder.
La phrase correcte est : 'Les cartes postales que j'ai envoyées à mes amis étaient magnifiques.' (envoyées, avec un e et un s)
Problème 2 — Un verbe pronominal piégeux
Avancé

Accorde correctement et justifie : 'Ils se sont ___ (rencontrer) dans un café.' vs 'Ils se sont ___ (parler) longtemps au téléphone.'

Pour 'se rencontrer' : 'se' est COD (ils ont rencontre QUI ? l un l autre). Accord avec le sujet masculin pluriel : 'rencontrés'.
Pour 'se parler' : 'se' est COI (parler A quelqu un). Le participe reste invariable : 'Ils se sont parlé longtemps au telephone.' Ces deux verbes pronominaux, tres proches en apparence, suivent donc des regles d accord differentes selon la construction du verbe.
Problème 3 — Un texte de dictée classique
Avancé

Analyse et corrige si nécessaire : 'La maison qu'ils ont construit se trouve au bord de la rivière.'

On cherche le COD du verbe 'construire' : ils ont construit QUOI ? 'qu' (que), qui reprend 'la maison' (feminin singulier).
Ce COD est place AVANT le verbe : il faut donc accorder le participe.
La phrase correcte est : 'La maison qu'ils ont construite se trouve au bord de la riviere.' (construite, avec un e)
Problème 4 — Distinguer deux cas avec le même verbe
Avancé

Explique la différence d'accord entre ces deux phrases : A) 'Elle s'est coupée.' B) 'Elle s'est coupé le doigt.'

Phrase A : 'se' est COD (elle a coupe QUI ? elle-meme). On accorde donc avec le sujet feminin : 'coupée'.
Phrase B : ici, le COD reel est 'le doigt' (elle a coupe QUOI ? le doigt), place APRES le verbe. Le pronom 'se' devient alors COI (a qui ? a elle-meme). Comme le COD est apres le verbe, le participe reste invariable : 'Elle s'est coupé le doigt.' Ce type de piege est tres frequent au brevet.
