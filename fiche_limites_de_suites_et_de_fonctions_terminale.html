Série 1 — Limites de suites

Suites convergentes, divergentes, suites géométriques et opérations

📖 Limite finie, limite infinie : définitions

Une suite (uₙ) a pour limite un réel ℓ lorsque les termes uₙ se rapprochent autant qu on veut de ℓ dès que l indice n est assez grand. On dit alors que la suite converge vers ℓ. Une suite a pour limite +∞ lorsque les termes deviennent aussi grands que l on veut dès que n est assez grand ; on parle alors de limite infinie et la suite est dite divergente. Une suite qui n a pas de limite, comme uₙ = (−1)ⁿ, est aussi divergente.

lim uₙ = ℓ (n → +∞) : la suite converge vers ℓ lim uₙ = +∞ : les termes dépassent tout réel A à partir d un certain rang Si une suite converge, sa limite est unique
Trois comportements différents uₙ = 1/n : les termes 1 ; 0,5 ; 0,33 ; 0,25 ... se rapprochent de 0, donc lim uₙ = 0. vₙ = n² : les termes 1 ; 4 ; 9 ; 16 ... deviennent arbitrairement grands, donc lim vₙ = +∞. wₙ = (−1)ⁿ : les termes valent −1 ; 1 ; −1 ; 1 ... et n ont pas de limite.
Convergente ne veut pas dire bornée par la limiteUne suite peut converger vers ℓ en oscillant autour de ℓ. Ce qui compte est que l écart |uₙ − ℓ| devienne aussi petit que l on veut, pas que la suite soit croissante ou décroissante.
"La suite (uₙ) converge vers ℓ car ses termes se rapprochent de ℓ lorsque n tend vers +∞."
📊 Visualiser une limite de suite
1À gauche : les points se rapprochent de la droite y = ℓ (en pointillés) : la suite converge vers ℓ = 2.
2À droite : les points dépassent n’importe quelle hauteur : la limite est +∞.
3Une limite se lit à droite du graphique, quand n devient grand.
📖 Limites de référence et suites géométriques

Il faut connaître par cœur les limites des suites usuelles, car tous les calculs s y ramènent. Pour une suite géométrique de terme général qⁿ, tout dépend de la valeur de la raison q : si q est supérieur à 1 la suite explose vers +∞, si q est compris strictement entre −1 et 1 elle s écrase vers 0, et si q est inférieur ou égal à −1 elle oscille sans limite.

lim 1/n = 0 ; lim 1/√n = 0 ; lim 1/n² = 0 lim n = +∞ ; lim n² = +∞ ; lim √n = +∞ q > 1 : lim qⁿ = +∞ −1 < q < 1 : lim qⁿ = 0 q = 1 : qⁿ = 1 constante ; q ≤ −1 : qⁿ n a pas de limite

Appliquer le critère sur q (1,5)ⁿ : 1,5 > 1 donc la limite est +∞. (2/3)ⁿ : 0 < 2/3 < 1 donc la limite est 0. (−0,9)ⁿ : −1 < −0,9 < 0 donc la limite est 0. (−3)ⁿ : −3 ≤ −1 donc la suite oscille et n a pas de limite.
Ne pas confondre q et sa valeur absolue(−2)ⁿ ne tend pas vers +∞ : il change de signe à chaque terme. Seule la condition q > 1 (strictement positif) donne +∞.
"La raison q vérifie −1 < q < 1, donc la suite géométrique (qⁿ) converge vers 0."

3−1 < q < 0 (violet) : qⁿ tend vers 0 en alternant les signes.
4q ≤ −1 : pas de limite (la suite oscille sans se stabiliser).
📖 Opérations sur les limites et formes indéterminées

On peut additionner, multiplier et diviser des limites, mais certaines combinaisons ne permettent pas de conclure : on les appelle formes indéterminées. Dans ces cas, il faut transformer l expression (factoriser le terme dominant, simplifier) avant de passer à la limite. Les quatre formes indéterminées à connaître sont +∞ − ∞, 0 × ∞, ∞/∞ et 0/0.

Quotient : si lim vₙ = ℓ' ≠ 0, alors lim uₙ/vₙ = ℓ/ℓ' ℓ/0⁺ = +∞ si ℓ > 0 ; ℓ/0⁻ = −∞ si ℓ > 0 ℓ/±∞ = 0 Formes indéterminées : +∞ − ∞ ; 0 × ∞ ; ∞/∞ ; 0/0
🔢 Lever une forme indéterminée pour un polynôme ou une fraction
  • Repérer le terme de plus haut degré (le terme dominant) au numérateur et au dénominateur.
  • Factoriser ce terme dominant dans chaque expression.
  • Simplifier la fraction, puis utiliser les limites de référence (1/n tend vers 0).
  • Conclure avec les opérations sur les limites.

uₙ = (3n² + 2n) / (n² + 1) Numérateur et dénominateur tendent vers +∞ : forme indéterminée ∞/∞. On factorise n² : uₙ = n²(3 + 2/n) / [n²(1 + 1/n²)] = (3 + 2/n) / (1 + 1/n²). Or 2/n tend vers 0 et 1/n² tend vers 0, donc uₙ tend vers 3/1 = 3.
Pour une fraction de polynômes, regarder les degrésSi les degrés sont égaux, la limite est le quotient des coefficients dominants ; si le numérateur est de plus grand degré, la limite est infinie ; s il est de plus petit degré, la limite est 0.
"On est en présence d une forme indéterminée ∞/∞ ; on factorise le terme dominant au numérateur et au dénominateur avant de passer à la limite."
📖 Théorèmes de comparaison et d encadrement

Quand une suite est trop compliquée pour calculer sa limite directement, on la compare à une suite plus simple dont on connaît le comportement. Le théorème de comparaison permet de conclure à une limite infinie, le théorème d encadrement (dit des gendarmes) permet de conclure à une limite finie. Un dernier résultat, le théorème de convergence monotone, garantit la convergence d une suite croissante et majorée (ou décroissante et minorée).

Minoration : si uₙ ≥ vₙ à partir d un certain rang et lim vₙ = +∞, alors lim uₙ = +∞ Majoration : si uₙ ≤ vₙ à partir d un certain rang et lim vₙ = −∞, alors lim uₙ = −∞ Gendarmes : si vₙ ≤ uₙ ≤ wₙ et lim vₙ = lim wₙ = ℓ, alors lim uₙ = ℓ Toute suite croissante et majorée converge ; toute suite décroissante et minorée converge
🔢 Utiliser un théorème de comparaison
  • Trouver un encadrement ou une minoration en partant de l expression de uₙ (par exemple −1 ≤ (−1)ⁿ ≤ 1).
  • Vérifier que la comparaison est valable pour tout n (ou à partir d un certain rang).
  • Calculer les limites des suites qui encadrent.
  • Citer le théorème utilisé et conclure.
uₙ = (−1)ⁿ / n Pour tout n ≥ 1, on a −1 ≤ (−1)ⁿ ≤ 1. En divisant par n > 0 : −1/n ≤ uₙ ≤ 1/n. Comme −1/n et 1/n tendent tous deux vers 0, le théorème des gendarmes donne lim uₙ = 0.
Penser à (−1)ⁿ, cos n, sin nCes expressions oscillent mais restent comprises entre −1 et 1 : elles sont idéales pour construire un encadrement, à condition de les multiplier ou diviser par une quantité positive.
"Pour tout n, vₙ ≤ uₙ ≤ wₙ avec lim vₙ = lim wₙ = ℓ ; d après le théorème d encadrement, la suite (uₙ) converge vers ℓ."
📊 Théorème des gendarmes (encadrement)
1Si uₙ ≤ vₙ ≤ wₙ et que uₙ et wₙ tendent vers la même limite ℓ, alors vₙ est « coincée » entre elles.
2Ici uₙ → 2 et wₙ → 2, donc la suite noire vₙ = 2 + cos(n)/n tend aussi vers 2.

Série 2 — Limites de fonctions

Limites en ±∞, limites en un réel a, asymptotes et opérations

📖 Limite finie ou infinie en l infini ; asymptote horizontale

Pour une fonction f, la limite en +∞ décrit le comportement de f(x) lorsque x devient très grand. Si f(x) se rapproche d un réel ℓ, la droite d équation y = ℓ est une asymptote horizontale à la courbe de f. Si f(x) devient aussi grand que l on veut, la limite est +∞ et la courbe monte sans borne. Le même raisonnement vaut en −∞.

lim f(x) = ℓ (x → +∞) : la droite y = ℓ est asymptote horizontale en +∞ lim 1/x = 0 ; lim 1/x² = 0 ; lim 1/√x = 0 (x → +∞) lim x = +∞ ; lim x² = +∞ ; lim x³ = +∞ ; lim √x = +∞ (x → +∞) lim x² = +∞ et lim x³ = −∞ (x → −∞)
f(x) = 2 + 1/x Lorsque x tend vers +∞, 1/x tend vers 0. Donc f(x) tend vers 2 + 0 = 2. La droite d équation y = 2 est asymptote horizontale à la courbe en +∞ (et aussi en −∞).
Attention au signe en −∞Pour les puissances impaires, x³ tend vers −∞ quand x tend vers −∞, alors que x² tend vers +∞. Multiplier par un coefficient négatif inverse encore le signe.
"Comme f(x) tend vers ℓ quand x tend vers +∞, la droite d équation y = ℓ est asymptote horizontale à la courbe représentative de f."
📖 Limite infinie en un réel a ; asymptote verticale

Une fonction peut tendre vers l infini lorsque x s approche d un réel a, en général à cause d un dénominateur qui s annule. On étudie alors séparément la limite à gauche (x < a) et la limite à droite (x > a), en déterminant le signe du dénominateur. Si la limite est infinie, la droite d équation x = a est une asymptote verticale.

lim 1/x = +∞ quand x → 0 par valeurs supérieures (0⁺) lim 1/x = −∞ quand x → 0 par valeurs inférieures (0⁻) lim 1/x² = +∞ quand x → 0 (des deux côtés) Si lim f(x) = ±∞ quand x → a, la droite x = a est asymptote verticale
🔢 Étudier une limite en une valeur interdite
  • Calculer la limite du numérateur (un réel non nul) et déterminer le signe du dénominateur de chaque côté de a.
  • Écrire le dénominateur sous la forme 0⁺ ou 0⁻ selon le côté.
  • Appliquer la règle des signes pour le quotient.
  • Conclure en donnant la limite à gauche, la limite à droite et l asymptote verticale.
f(x) = (2x + 1) / (x − 3) en x = 3 Au voisinage de 3, le numérateur tend vers 2×3 + 1 = 7 > 0. Pour x > 3 (x tend vers 3 par valeurs supérieures), x − 3 est positif et tend vers 0⁺ : la limite est +∞. Pour x < 3, x − 3 est négatif et tend vers 0⁻ : la limite est −∞. La droite x = 3 est asymptote verticale.
Un tableau de signes évite les erreursDès qu un dénominateur s annule, dresser le tableau de signes de x − a (ou du facteur qui s annule) permet de décider entre +∞ et −∞ de façon fiable.
"Le numérateur tend vers un réel positif et le dénominateur tend vers 0⁺, donc le quotient tend vers +∞ ; la droite x = a est asymptote verticale."
📊 Asymptotes : lire les limites sur la courbe
1Asymptote horizontale y = 2 (vert) : lim f(x) = 2 quand x → +∞ et x → −∞.
2Asymptote verticale x = 0 (orange) : f(x) → +∞ quand x → 0⁺ et f(x) → −∞ quand x → 0⁻.
3La courbe se rapproche de la droite sans la traverser près de l’asymptote.
📖 Opérations, formes indéterminées et fractions rationnelles

Les règles d opérations sont les mêmes que pour les suites. Pour une fonction polynôme, la limite en ±∞ est celle de son terme de plus haut degré. Pour une fonction rationnelle, c est le quotient des termes de plus haut degré du numérateur et du dénominateur. Pour les expressions avec racine carrée de type √(x+1) − √x, on multiplie par la quantité conjuguée pour lever la forme indéterminée +∞ − ∞.

Polynôme : lim P(x) en ±∞ = lim du terme de plus haut degré Fraction rationnelle : lim P(x)/Q(x) en ±∞ = lim du quotient des termes dominants Quantité conjuguée : √a − √b = (a − b) / (√a + √b)
🔢 Lever une forme indéterminée avec un radical
  • Reconnaître la forme +∞ − ∞ avec des racines carrées.
  • Multiplier et diviser par la quantité conjuguée √a + √b.
  • Utiliser l identité (√a − √b)(√a + √b) = a − b pour obtenir une fraction.
  • Calculer la limite de la fraction obtenue.
Limite de √(x + 1) − √x en +∞ C est la forme indéterminée +∞ − ∞. On multiplie par la quantité conjuguée : √(x+1) − √x = [(x+1) − x] / [√(x+1) + √x] = 1 / [√(x+1) + √x]. Le dénominateur tend vers +∞, donc la fraction tend vers 0. La limite est 0.
Exemple de fraction rationnellelim (3x² + x) / (x² − 1) en +∞ : on garde les termes dominants 3x² / x² = 3. La limite vaut 3 et la droite y = 3 est asymptote horizontale.
"Pour lever cette forme indéterminée, on factorise le terme de plus haut degré (ou on multiplie par la quantité conjuguée) avant de passer à la limite."
📖 Comparaison et encadrement pour les fonctions

Les théorèmes de comparaison et d encadrement s énoncent comme pour les suites. Ils permettent de traiter des fonctions contenant sin x ou cos x, qui n ont pas de limite mais restent bornées entre −1 et 1.

Si f(x) ≥ g(x) pour x grand et lim g = +∞ alors lim f = +∞ Si g(x) ≤ f(x) ≤ h(x) et lim g = lim h = ℓ alors lim f = ℓ lim (sin x)/x = 0 quand x → +∞
lim (sin x) / x en +∞ Pour tout x > 0, −1 ≤ sin x ≤ 1, donc −1/x ≤ (sin x)/x ≤ 1/x. Comme −1/x et 1/x tendent vers 0 en +∞, le théorème d encadrement donne lim (sin x)/x = 0.
Une fonction peut croître malgré les oscillationsf(x) = x + sin x vérifie f(x) ≥ x − 1, donc tend vers +∞ par comparaison, bien que sin x oscille.
"Pour tout x > 0, g(x) ≤ f(x) ≤ h(x) ; comme g et h ont la même limite ℓ, f a aussi pour limite ℓ d après le théorème des gendarmes."

Série 3 — Limites et fonction exponentielle

Limites de eˣ, croissances comparées et taux d accroissement en 0

📖 Limites de la fonction exponentielle

La fonction exponentielle x ↦ eˣ est strictement positive et croissante sur ℝ. Elle tend vers +∞ en +∞ et vers 0 en −∞ (sans jamais s annuler). La courbe de l exponentielle admet donc l axe des abscisses comme asymptote horizontale en −∞. On utilise aussi la limite en 0 liée au nombre dérivé de eˣ en 0.

lim eˣ = +∞ (x → +∞) lim eˣ = 0 (x → −∞) : la droite y = 0 est asymptote en −∞ lim (eˣ − 1)/x = 1 (x → 0) lim e⁻ˣ = 0 (x → +∞) car e⁻ˣ = 1/eˣ
Quelques limites immédiates lim (eˣ + 1) en +∞ : eˣ tend vers +∞, donc la limite est +∞. lim (3 − eˣ) en +∞ : 3 − (grand nombre positif) tend vers −∞. lim (2 + e⁻ˣ) en +∞ : e⁻ˣ tend vers 0 donc la limite est 2. lim (e²ˣ − 1)/x en 0 : (e²ˣ − 1)/x = 2 × (e²ˣ − 1)/(2x), qui tend vers 2 × 1 = 2.
Reconnaître le taux d accroissementLa limite (eˣ − 1)/x quand x tend vers 0 est le nombre dérivé de eˣ en 0, qui vaut e⁰ = 1. Pour (e^{kx} − 1)/x, on pose X = kx pour se ramener à cette limite, ce qui donne k.
"La fonction exponentielle tend vers +∞ en +∞ et vers 0 en −∞ ; la droite y = 0 est donc asymptote horizontale à sa courbe en −∞."
📖 Croissances comparées

Quand on croise une puissance de x avec eˣ, c est l exponentielle qui l emporte en +∞, et ce, quelle que soit la puissance. C est ce que l on appelle les croissances comparées. Elles permettent de lever les formes indéterminées du type ∞/∞ ou 0 × ∞ faisant intervenir eˣ.

Pour tout entier n : lim eˣ / xⁿ = +∞ (x → +∞) Pour tout entier n : lim xⁿ e⁻ˣ = 0 (x → +∞) lim x eˣ = 0 (x → −∞)
🔢 Utiliser les croissances comparées
  • Repérer le produit ou le quotient entre une puissance de x et eˣ.
  • Se ramener à l une des trois limites de cours (ou à son inverse).
  • Factoriser eˣ si besoin pour faire apparaître une forme connue.
  • Conclure par les opérations sur les limites.
lim (eˣ − x) en +∞ C est la forme indéterminée +∞ − ∞. On factorise eˣ : eˣ − x = eˣ (1 − x/eˣ). Par croissances comparées, x/eˣ tend vers 0, donc 1 − x/eˣ tend vers 1. Comme eˣ tend vers +∞, le produit tend vers +∞.
L exponentielle gagne toujoursEn +∞, eˣ est plus grand que n importe quelle puissance de x. En −∞, au contraire, c est l exponentielle qui est écrasée vers 0, et x eˣ tend vers 0.
"Par croissances comparées, la fonction exponentielle l emporte sur toute puissance de x en +∞, donc xⁿ e⁻ˣ tend vers 0."
📊 L’exponentielle l’emporte sur les puissances
1Quand x → −∞, eˣ → 0 : l’axe des abscisses est asymptote à la courbe de eˣ.
2Quand x → +∞, eˣ → +∞ et finit par dépasser x² (et toute puissance de x) : eˣ / xⁿ → +∞.
3C’est l’idée des croissances comparées.

Appliquer les limites à des situations concrètes

Problème 1 — Dose de médicament dans le sang
Intermédiaire

Un patient reçoit chaque jour une injection qui apporte 2 mg de médicament. Chaque jour, l organisme élimine la moitié de la quantité présente avant l injection. On note dₙ la quantité (en mg) présente après n jours, avec d₀ = 0 et dₙ₊₁ = 0,5 dₙ + 2. On admet que dₙ = 4 − 4 × (0,5)ⁿ. Calculer d₁ et d₂, puis déterminer la limite de dₙ et interpréter le résultat.

On calcule directement avec la relation de récurrence : d₁ = 0,5 × 0 + 2 = 2 mg, puis d₂ = 0,5 × 2 + 2 = 3 mg. On vérifie avec la formule : d₂ = 4 − 4 × 0,25 = 3, ce qui est cohérent.
La suite (0,5)ⁿ est géométrique de raison 0,5, comprise entre −1 et 1, donc elle converge vers 0.
Par produit et somme de limites, 4 × (0,5)ⁿ tend vers 0 et dₙ tend vers 4 − 0 = 4.
Interprétation : la quantité de médicament se stabilise vers 4 mg, la dose reste donc sous un seuil de sécurité d environ 4 mg quel que soit le nombre de jours.
Problème 2 — Placer de l argent
Intermédiaire

On place 1000 euros à intérêts composés au taux de 3 % par an. On note uₙ le capital au bout de n années. Exprimer uₙ en fonction de n, déterminer la limite de uₙ puis trouver au bout de combien d années le capital aura doublé (on pourra utiliser la calculatrice).

Chaque année le capital est multiplié par 1,03 : (uₙ) est donc géométrique de premier terme u₀ = 1000 et de raison 1,03. Ainsi uₙ = 1000 × 1,03ⁿ.
Comme 1,03 est strictement supérieur à 1, 1,03ⁿ tend vers +∞ et donc lim uₙ = +∞ : en théorie, le capital croît sans borne.
Le capital doublé correspond à uₙ ≥ 2000, c est-à-dire 1,03ⁿ ≥ 2. Avec la calculatrice, 1,03²³ ≈ 1,974 (insuffisant) et 1,03²⁴ ≈ 2,033 (suffisant).
Le capital aura donc doublé au bout de 24 ans.
Problème 3 — Coût moyen de fabrication
Intermédiaire

Une entreprise fabrique x objets (x > 0). Ses coûts fixes sont de 200 euros et chaque objet coûte 5 euros à produire. Exprimer le coût moyen C(x) par objet, puis étudier sa limite quand x tend vers +∞ et quand x tend vers 0 par valeurs supérieures. Interpréter.

Le coût total pour x objets est 5x + 200, donc le coût moyen est C(x) = (5x + 200) / x = 5 + 200/x.
Quand x tend vers +∞, 200/x tend vers 0, donc lim C(x) = 5 : le coût moyen se rapproche de 5 euros, qui est le coût de production d un objet sans les coûts fixes.
Quand x tend vers 0 par valeurs supérieures, 200/x tend vers +∞ donc lim C(x) = +∞ : avec très peu d objets, les coûts fixes pèsent énormément sur chaque objet.
La courbe de C admet la droite y = 5 comme asymptote horizontale et l axe des ordonnées x = 0 comme asymptote verticale.
Problème 4 — Refroidissement d une boisson
Avancé

La température (en degrés Celsius) d une boisson posée dans une pièce à 20 degrés est donnée au bout de t minutes par T(t) = 20 + 60 e^(−0,1 t). Calculer T(0), la limite de T quand t tend vers +∞, et une valeur approchée de T(30). Interpréter ces résultats.

À l instant initial, T(0) = 20 + 60 e⁰ = 20 + 60 = 80 degrés : la boisson est chaude au départ.
Quand t tend vers +∞, −0,1 t tend vers −∞ donc e^(−0,1 t) tend vers 0. Par suite lim T(t) = 20 degrés.
Pour t = 30 : T(30) = 20 + 60 e⁻³. Comme e⁻³ ≈ 0,0498, on obtient T(30) ≈ 20 + 2,99 = environ 23 degrés.
Interprétation : la boisson refroidit et sa température se rapproche de celle de la pièce sans jamais descendre en dessous, ce qui se lit sur le graphique par l asymptote horizontale d équation y = 20.

Exercice 1 — Limites de suites
5 pts
— 2,5 ptsDéterminer la limite de la suite uₙ = (4n² − n + 3) / (2n² + 5) en justifiant.
Calculs…
✔ Correction — Barème : 1 pt pour la forme indéterminée reconnue, 1 pt pour la factorisation, 0,5 pt pour la conclusion
Le numérateur et le dénominateur tendent vers +∞ : forme indéterminée ∞/∞. On factorise n² : uₙ = n²(4 − 1/n + 3/n²) / [n²(2 + 5/n²)] = (4 − 1/n + 3/n²) / (2 + 5/n²). Comme 1/n, 3/n² et 5/n² tendent vers 0, le numérateur tend vers 4 et le dénominateur vers 2. lim uₙ = 4/2 = 2.
— 2,5 ptsDéterminer la limite de la suite vₙ = 5 × (0,8)ⁿ − 2 puis celle de wₙ = 3ⁿ − 2ⁿ.
Calculs…
✔ Correction — Barème : 1 pt pour vₙ, 1,5 pt pour wₙ
Pour vₙ : la raison 0,8 est comprise entre −1 et 1, donc (0,8)ⁿ tend vers 0 ; ainsi lim vₙ = 5 × 0 − 2 = −2. Pour wₙ : on a la forme indéterminée +∞ − ∞. On factorise 3ⁿ : wₙ = 3ⁿ(1 − (2/3)ⁿ). Comme (2/3)ⁿ tend vers 0, le facteur (1 − (2/3)ⁿ) tend vers 1 ; 3ⁿ tend vers +∞. Par produit, lim wₙ = +∞.
Exercice 2 — Comparaison et encadrement
4 pts
— 2 ptsMontrer que la suite uₙ = (cos n) / n converge et préciser sa limite.
Calculs…
✔ Correction — Barème : 1 pt pour l encadrement, 1 pt pour le théorème des gendarmes
Pour tout entier n ≥ 1, −1 ≤ cos n ≤ 1. En divisant par n > 0, on obtient −1/n ≤ uₙ ≤ 1/n. Les suites −1/n et 1/n convergent toutes deux vers 0. D après le théorème d encadrement, (uₙ) converge vers 0.
— 2 ptsMontrer que la suite vₙ = n² + (−1)ⁿ n diverge vers +∞.
Calculs…
✔ Correction — Barème : 1 pt pour la minoration, 1 pt pour le théorème de comparaison
Pour tout n, (−1)ⁿ ≥ −1 donc (−1)ⁿ n ≥ −n et vₙ ≥ n² − n = n(n − 1). La suite n(n − 1) tend vers +∞ (produit de deux suites qui tendent vers +∞). Par le théorème de comparaison, lim vₙ = +∞.
Exercice 3 — Fonction rationnelle et asymptotes
6 pts
— 3 ptsSoit f(x) = (3x − 2) / (x + 1) définie sur ]−1 ; +∞[. Déterminer les limites de f en +∞ et en −1 (par valeurs supérieures).
Calculs…
✔ Correction — Barème : 1,5 pt par limite correctement justifiée
Limite en +∞ : f(x) = x(3 − 2/x) / [x(1 + 1/x)] = (3 − 2/x) / (1 + 1/x), qui tend vers 3. Donc lim f(x) = 3. Limite en −1⁺ : le numérateur tend vers 3×(−1) − 2 = −5, négatif ; le dénominateur x + 1 tend vers 0⁺. Un quotient d un nombre négatif par 0⁺ tend vers −∞ : lim f(x) = −∞ en −1⁺.
— 3 ptsInterpréter graphiquement les deux résultats précédents, puis déterminer lim (√(x² + 1) − x) en +∞.
Calculs…
✔ Correction — Barème : 1 pt pour les asymptotes, 2 pts pour le radical
La droite y = 3 est asymptote horizontale à la courbe en +∞, et la droite x = −1 est asymptote verticale. Pour le radical, forme indéterminée +∞ − ∞ : on multiplie par la quantité conjuguée √(x²+1) + x. √(x²+1) − x = [(x²+1) − x²] / [√(x²+1) + x] = 1 / [√(x²+1) + x]. Le dénominateur tend vers +∞, donc lim = 0.

5 pts

C est la forme indéterminée +∞ − ∞. On factorise eˣ : eˣ − x² = eˣ (1 − x²/eˣ). Par croissances comparées, x²/eˣ tend vers 0, donc le facteur tend vers 1. Comme eˣ tend vers +∞, lim (eˣ − x²) = +∞.
