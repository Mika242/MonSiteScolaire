Série 1 — Définir une fonction

Image, antécédent, ensemble de définition

📖 La notion de fonction

Une fonction f, définie sur une partie D de R, associe a tout x de D un UNIQUE nombre, note f(x). Cette notion, déjà vue en troisieme, est le socle de toute l analyse mathematique du lycee.

f : D → R, x ↦ f(x)
TermeSignification
D (ensemble de définition)L ensemble des x pour lesquels f(x) existe
x (antecedent)La valeur de depart
f(x) (image)Le résultat associe a x
Ne jamais confondre image et antécédentL image se lit après avoir applique la fonction (le résultat). L antecedent est la valeur de depart, AVANT application de la fonction. Une même fonction peut avoir plusieurs antecedents pour une même image, mais un antecedent donne n a jamais qu une seule image.
📖 Déterminer l'ensemble de définition

Pour certaines fonctions, il faut exclure certaines valeurs de x qui rendraient le calcul de f(x) impossible : denominateur nul, ou expression négative sous une racine carree.

🔢 Méthode pour trouver l'ensemble de définition
  • Reperer les denominateurs présents dans l expression de f(x).
  • Poser chaque denominateur différent de zero, et résoudre pour trouver les valeurs interdites.
  • Reperer les expressions sous une racine carree.
  • Poser chaque expression sous racine superieure ou egale a zero, et résoudre.
Type de fonctionEnsemble de définition
Polynome (ex: f(x)=2x+3)R (tout reel convient)
Inverse (ex: f(x)=1/x)R* = R privé de {0}
Racine carree (ex: f(x)=√x)[0;+∞[
Quotient (ex: f(x)=1/(x-3))R privé de {3}

Q3 Avancé

Pour qu une racine carree existe, l expression sous la racine doit être positive ou nulle.
On pose donc la condition : x-2 ≥ 0.
On resout : x ≥ 2. L ensemble de définition de f est donc [2;+∞[.

Série 2 — Étudier les variations d'une fonction

Croissance, décroissance, extremums, parité

📖 Croissance et décroissance

Une fonction est croissante sur un intervalle si, quand x augmente, f(x) augmente aussi (ou reste egal). Elle est decroissante si, quand x augmente, f(x) diminue.

f croissante sur I si : x1<x2 ⟹ f(x1)≤f(x2), pour tout x1,x2 dans I f decroissante sur I si : x1<x2 ⟹ f(x1)≥f(x2), pour tout x1,x2 dans I
Exemple de tableau de variations Pour une fonction decroissante puis croissante, avec un minimum en x=0 : x: -∞ ... 0 ... +∞ f(x): descend jusqu au minimum, puis remonte
📖 Les extremums

Un extremum est une valeur maximale ou minimale prise par la fonction. On distingue les extremums locaux (sur un petit intervalle autour d un point) des extremums globaux (sur tout l ensemble de définition).

Ne pas confondre le maximum et sa positionLe maximum est la VALEUR maximale atteinte par f(x). Le x pour lequel cette valeur est atteinte est différent : c est l antecedent du maximum, pas le maximum lui-même.
📖 La parité d'une fonction

La parite d une fonction decrit une symetrie particuliere de sa courbe representative. Une fonction paire a une courbe symetrique par rapport a l axe des ordonnees ; une fonction impaire a une courbe symetrique par rapport a l origine du repere.

f paire : f(-x) = f(x) pour tout x du domaine f impaire : f(-x) = -f(x) pour tout x du domaine
Exemple résolu : tester la parité f(x) = x² : f(-x) = (-x)² = x² = f(x), donc f est paire f(x) = x³ : f(-x) = (-x)³ = -x³ = -f(x), donc f est impaire

Étudie la parité de la fonction f(x) = x² + 1, en détaillant ta méthode.

On calcule f(-x) : f(-x) = (-x)² + 1 = x² + 1.

Problèmes — Contextes variés

Les fonctions en situation

Problème 1 — Coût de production
Intermédiaire

Une entreprise a un coût de production modélisé par f(x) = 200 + 5x, où x est le nombre d'objets produits. Calcule f(50) et interprète le résultat.

On calcule l image de 50 : f(50) = 200 + 5×50 = 200+250 = 450.
Cela signifie que produire 50 objets coute 450 euros a l entreprise.
Problème 2 — Lecture graphique d'antécédents
Intermédiaire

Sur le graphique d'une fonction f, la droite horizontale y=3 coupe la courbe en deux points, d'abscisses -2 et 4. Que peut-on en conclure sur les antécédents de 3 ?

Les abscisses des points d intersection entre la courbe et la droite y=3 sont les antecedents de 3 par la fonction f.
On peut conclure que 3 a deux antecedents par f : -2 et 4, c est-a-dire que f(-2)=3 et f(4)=3.
Problème 3 — Ensemble de définition d'une fonction composée
Avancé

Détermine l'ensemble de définition de la fonction f(x) = 1/√(x+4), en combinant les deux conditions nécessaires.

Il y a deux conditions a respecter : l expression sous la racine doit être positive OU nulle, ET le denominateur ne doit pas être nul.
Condition 1 : x+4 ≥ 0, soit x ≥ -4.
Condition 2 : comme la racine est au denominateur, elle ne doit même pas être nulle (division par zero interdite), donc x+4 > 0 strictement, soit x > -4. L ensemble de définition est donc ]-4;+∞[.
Problème 4 — Étudier la parité d'une fonction non paire ni impaire
Avancé

Étudie la parité de la fonction f(x) = x² + x, en détaillant ta méthode et ta conclusion.

On calcule f(-x) : f(-x) = (-x)² + (-x) = x² - x.
On compare avec f(x) = x²+x : f(-x) ≠ f(x) (car x²-x ≠ x²+x sauf si x=0), donc f n est pas paire.
On compare aussi avec -f(x) = -x²-x : f(-x) = x²-x ≠ -f(x) non plus. La fonction f n est donc NI paire NI impaire.
