Développer une expression littérale

Distributivité simple, double distributivité et identités remarquables

📖 La distributivité simple

Développer une expression signifie transformer un produit en une somme ou une différence de termes. La propriété de distributivité permet de multiplier un nombre ou une expression par une somme (ou une différence).

k(a + b) = ka + kb k(a - b) = ka - kb
🔢 Méthode pour développer avec la distributivité simple
  • Identifier le facteur commun situé devant la parenthèse.
  • Multiplier ce facteur par chaque terme à l intérieur de la parenthèse.
  • Écrire le résultat sous forme de somme ou de différence, en respectant les signes.
  • Réduire les termes semblables s il y en a.
Exemple résolu Développons 5(3x - 4). On multiplie 5 par chaque terme : 5 × 3x = 15x et 5 × (-4) = -20. Donc 5(3x - 4) = 15x - 20.
Astuce et piège fréquentAttention au signe moins devant la parenthèse : -2(x + 3) = -2x - 6 et non -2x + 6. Le signe moins s applique à tous les termes.
"En appliquant la distributivité, on obtient …"
📖 La double distributivité

Lorsque l on multiplie deux sommes (ou différences), on utilise la double distributivité : chaque terme de la première parenthèse multiplie chaque terme de la seconde.

(a + b)(c + d) = ac + ad + bc + bd
🔢 Méthode pour développer un produit de deux binômes
  • Multiplier le premier terme de la première parenthèse par chacun des termes de la seconde.
  • Multiplier le second terme de la première parenthèse par chacun des termes de la seconde.
  • Écrire tous les produits obtenus et réduire les termes semblables.
Exemple résolu Développons (2x + 3)(x - 5). 2x × x = 2x² ; 2x × (-5) = -10x ; 3 × x = 3x ; 3 × (-5) = -15. On obtient 2x² - 10x + 3x - 15 = 2x² - 7x - 15.
AstuceOn peut visualiser la double distributivité comme un tableau à double entrée pour éviter d oublier un produit.
"En développant par double distributivité, on trouve …"
📖 Les identités remarquables

Certaines formes de développement reviennent très souvent. On les appelle identités remarquables. Elles permettent d aller plus vite et de limiter les erreurs de calcul.

(a + b)² = a² + 2ab + b² (a - b)² = a² - 2ab + b² (a + b)(a - b) = a² - b²
🔢 Comment reconnaître et appliquer une identité remarquable
  • Identifier la forme de l expression (carré d une somme, carré d une différence ou produit de somme par différence).
  • Repérer les valeurs de a et de b.
  • Remplacer directement dans la formule correspondante.
  • Simplifier si nécessaire.
FormeDéveloppement
(a + b)²a² + 2ab + b²
(a - b)²a² - 2ab + b²
(a + b)(a - b)a² - b²
Exemple résolu Développons (3x + 4)². Ici a = 3x et b = 4. (3x)² + 2 × 3x × 4 + 4² = 9x² + 24x + 16.
Piège classiqueNe jamais écrire (a + b)² = a² + b². Il manque toujours le double produit 2ab.

Q1 Facile

Que vaut 4(2x - 5) après développement ?

Q2 Facile

Développe l expression -3(x + 7). Écris le résultat sous la forme ax + b.

⭐⭐ Intermédiaire
Q3 Intermédiaire

Développe et réduis l expression (x + 5)(2x - 3).

On applique la double distributivité : x multiplie 2x et -3, puis 5 multiplie 2x et -3.
x × 2x = 2x² ; x × (-3) = -3x ; 5 × 2x = 10x ; 5 × (-3) = -15.
On additionne tous les termes : 2x² - 3x + 10x - 15.
On réduit les termes en x : -3x + 10x = 7x.
Le résultat final est 2x² + 7x - 15.
Q4 Intermédiaire

Développe (2x - 3)² en utilisant une identité remarquable.

On reconnaît le carré d une différence : (a - b)² avec a = 2x et b = 3.
La formule donne a² - 2ab + b².
(2x)² = 4x² ; 2 × 2x × 3 = 12x ; 3² = 9.
Donc (2x - 3)² = 4x² - 12x + 9.
Le résultat est 4x² - 12x + 9.
⭐⭐⭐ Avancé
Q5 Avancé

Développe et réduis l expression (x + 4)(x - 4) + (x + 2)².

On commence par le produit (x + 4)(x - 4) qui est une identité remarquable : a² - b² avec a = x et b = 4.
Cela donne x² - 16.
Ensuite on développe (x + 2)² = x² + 2 × x × 2 + 2² = x² + 4x + 4.
On additionne les deux résultats : (x² - 16) + (x² + 4x + 4) = 2x² + 4x - 12.
Le résultat final est 2x² + 4x - 12.

Factoriser une expression littérale

Mettre en évidence un facteur commun et utiliser les identités remarquables

📖 Factoriser avec un facteur commun

Factoriser consiste à transformer une somme ou une différence en un produit. La méthode la plus simple consiste à repérer un facteur commun à tous les termes et à le mettre en facteur.

ka + kb = k(a + b) ka - kb = k(a - b)
🔢 Méthode pour factoriser par un facteur commun
  • Repérer le plus grand facteur commun (nombre et éventuellement lettres) à tous les termes.
  • Écrire ce facteur devant une parenthèse.
  • Diviser chaque terme de l expression initiale par ce facteur commun et écrire les quotients à l intérieur de la parenthèse.
  • Vérifier en développant mentalement que l on retrouve l expression de départ.
Exemple résolu Factorisons 6x + 15. Le plus grand facteur commun est 3. 6x ÷ 3 = 2x et 15 ÷ 3 = 5. Donc 6x + 15 = 3(2x + 5).
AstuceSi les termes ont des signes différents, le facteur commun peut être négatif. Par exemple -4x + 8 = -4(x - 2).
"En mettant en évidence le facteur commun …, on obtient …"
📖 Factoriser avec les identités remarquables

Les identités remarquables fonctionnent aussi dans le sens de la factorisation. On reconnaît une somme ou une différence de termes qui correspond au développement d une identité, puis on revient à la forme produit.

a² + 2ab + b² = (a + b)² a² - 2ab + b² = (a - b)² a² - b² = (a + b)(a - b)
🔢 Méthode pour factoriser avec une identité remarquable
  • Observer si l expression ressemble à un carré parfait ou à une différence de carrés.
  • Identifier clairement a et b.
  • Écrire la forme factorisée correspondante.
  • Vérifier en développant si nécessaire.
Exemple résolu Factorisons x² - 10x + 25. On reconnaît a² - 2ab + b² avec a = x et b = 5, car 2 × x × 5 = 10x et 5² = 25. Donc x² - 10x + 25 = (x - 5)².
Piège fréquentPour une différence de carrés, il faut bien deux carrés. x² - 9 = (x + 3)(x - 3), mais x² - 9x n est pas une différence de carrés.
"En reconnaissant l identité …, on factorise sous la forme …"

Quelle est la factorisation correcte de 8x - 12 ?

Q2 Facile

Factorise l expression 5x + 20. Écris le résultat sous la forme k(ax + b).

⭐⭐ Intermédiaire
Q3 Intermédiaire

Factorise l expression 9x² - 16 en utilisant une identité remarquable.

On reconnaît une différence de carrés : a² - b² avec a = 3x (car (3x)² = 9x²) et b = 4 (car 4² = 16).
La formule donne (a + b)(a - b).
Donc 9x² - 16 = (3x + 4)(3x - 4).
Le résultat est (3x + 4)(3x - 4).
Q4 Intermédiaire

Factorise complètement l expression 2x² + 10x + 12.

On commence par mettre en évidence le facteur commun 2 : 2x² + 10x + 12 = 2(x² + 5x + 6).
On cherche maintenant à factoriser x² + 5x + 6. On cherche deux nombres dont le produit est 6 et la somme est 5 : ce sont 2 et 3.
Donc x² + 5x + 6 = (x + 2)(x + 3).
Finalement 2x² + 10x + 12 = 2(x + 2)(x + 3).
Le résultat est 2(x + 2)(x + 3).
⭐⭐⭐ Avancé
Q5 Avancé

Factorise l expression (2x + 1)² - 9.

On reconnaît une différence de carrés de la forme A² - B² avec A = 2x + 1 et B = 3.
Donc (2x + 1)² - 9 = (2x + 1 + 3)(2x + 1 - 3).
On simplifie : (2x + 4)(2x - 2).
On peut encore factoriser chaque parenthèse : 2x + 4 = 2(x + 2) et 2x - 2 = 2(x - 1).
Donc (2x + 4)(2x - 2) = 2(x + 2) × 2(x - 1) = 4(x + 2)(x - 1).
Le résultat complètement factorisé est 4(x + 2)(x - 1).

Problèmes — Contextes variés

Appliquer le développement et la factorisation dans des situations concrètes

Problème 1 — Aire d un jardin rectangulaire
Intermédiaire

Un jardin rectangulaire mesure (x + 5) mètres de longueur et (x + 2) mètres de largeur. Exprimer l aire du jardin en fonction de x, puis développer cette expression. Calculer l aire lorsque x = 8.

L aire d un rectangle est le produit de la longueur par la largeur. Donc l aire A est donnée par A = (x + 5)(x + 2).
On développe par double distributivité : x × x = x² ; x × 2 = 2x ; 5 × x = 5x ; 5 × 2 = 10.
On obtient A = x² + 2x + 5x + 10 = x² + 7x + 10.
Lorsque x = 8, A = 8² + 7 × 8 + 10 = 64 + 56 + 10 = 130.
L aire du jardin est de 130 m².
Problème 2 — Économies sur un achat groupé
Intermédiaire

Le prix d un article est (3x + 4) euros. Un client achète 5 articles identiques. Exprimer le prix total payé en fonction de x, puis développer. Quel est le prix total si x = 6 ?

Le prix total P est égal à 5 fois le prix d un article : P = 5(3x + 4).
On applique la distributivité simple : 5 × 3x = 15x et 5 × 4 = 20.
Donc P = 15x + 20.
Si x = 6, P = 15 × 6 + 20 = 90 + 20 = 110.
Le prix total est de 110 euros.
Problème 3 — Différence d aires de deux carrés
Avancé

On considère un grand carré de côté (x + 3) cm et un petit carré de côté 3 cm. Exprimer la différence des aires en fonction de x, puis factoriser cette expression. Calculer cette différence lorsque x = 5.

L aire du grand carré est (x + 3)² et celle du petit carré est 3² = 9.
La différence D des aires est D = (x + 3)² - 9.
On développe d abord (x + 3)² = x² + 6x + 9, donc D = x² + 6x + 9 - 9 = x² + 6x.
On peut factoriser x² + 6x = x(x + 6).
On peut aussi reconnaître directement une différence de carrés : (x + 3)² - 3² = (x + 3 + 3)(x + 3 - 3) = (x + 6)x.
Lorsque x = 5, D = 5(5 + 6) = 5 × 11 = 55.
La différence des aires est de 55 cm².
Problème 4 — Périmètre et aire d un cadre
Avancé

Un cadre photo rectangulaire a une longueur de (2x + 1) cm et une largeur de (x + 4) cm. Exprimer le périmètre en fonction de x, puis l aire. Développer l expression de l aire. Calculer le périmètre et l aire pour x = 3.

Le périmètre P d un rectangle est P = 2(longueur + largeur) = 2[(2x + 1) + (x + 4)] = 2(3x + 5) = 6x + 10.
L aire A est A = (2x + 1)(x + 4).
On développe : 2x × x = 2x² ; 2x × 4 = 8x ; 1 × x = x ; 1 × 4 = 4.
Donc A = 2x² + 8x + x + 4 = 2x² + 9x + 4.
Pour x = 3, le périmètre vaut 6 × 3 + 10 = 18 + 10 = 28 cm.
L aire vaut 2 × 9 + 9 × 3 + 4 = 18 + 27 + 4 = 49 cm².
Le périmètre est 28 cm et l aire est 49 cm².

On applique la double distributivité. x × 2x = 2x² ; x × (-5) = -5x ; 3 × 2x = 6x ; 3 × (-5) = -15. On obtient 2x² - 5x + 6x - 15. On réduit les termes en x : -5x + 6x = x. Le résultat final est 2x² + x - 15.

On reconnaît le carré d une différence (a - b)² avec a = 3x et b = 2. La formule donne a² - 2ab + b² = (3x)² - 2 × 3x × 2 + 2² = 9x² - 12x + 4. Le résultat est 9x² - 12x + 4.

Calculs…
✔ Correction — Barème : 1 pt pour l expression de l aire, 1,5 pt pour le développement, 1 pt pour le calcul numérique, 1,5 pt pour la factorisation.
